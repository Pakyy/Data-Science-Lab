INTRODUCTION

Dataset description

The dataset used in this project, provided by Banca d’Italia, is a comprehensive survey on financial literacy among Italian adults. The survey, part of an OECD initiative, aims to create an internationally comparable dataset to evaluate financial literacy and inclusion. It includes approximately 2,500 respondents who were interviewed using two different methods: face-to-face interviews and tablet-based responses. The dataset contains detailed socio-demographic information, financial knowledge scores, behavioral data on financial practices, and attitudes towards financial management. Key variables include gender, age, educational qualification, employment status, geographic location, and various aspects of financial behavior and attitudes.

Idea and motivations

Financial literacy is a critical factor for individual and household economic well-being. Despite the importance of financial knowledge, many individuals struggle with understanding basic financial concepts, which can lead to poor financial decisions and increased financial vulnerability.

The motivation behind this project is to analyze the current state of financial literacy in Italy, identify key factors influencing it, and develop targeted strategies to improve financial education. By leveraging this rich dataset, we can gain insights into the financial behaviors and attitudes of different demographic groups and understand how financial literacy impacts their financial decision-making.

Aim of the project

The primary aim of this project is to assess and improve financial literacy among Italian adults by conducting an analysis of the provided dataset. Specifically, the project has the following objectives:

Assess the Current Level of Financial Literacy: Evaluate the financial literacy scores across various demographic groups to understand the disparities and identify areas needing improvement.

Identify Key Influencing Factors: Determine the socio-demographic and economic factors that significantly impact financial literacy and financial behaviors.

Examine Financial Resilience: Analyze how different levels of financial literacy affect the ability of individuals to manage financial shocks and unexpected expenses.

Explore Financial Decision-Making: Investigate the relationship between financial literacy and the quality of financial decisions, such as investment choices and debt management.

Investigate Regional Disparities: Assess regional differences in financial literacy and access to financial education resources to identify areas where interventions are most needed.

Research question 1

Understanding the determinants of financial literacy through ordinal regression can inform policymakers and educators about:

  • Targeted educational programs for specific demographic groups.

  • Effective policy measures to improve financial literacy across different population segments.

  • Allocation of resources in areas where interventions are most needed.

# Funzione per ottenere regole diverse
get_diverse_rules <- function(rules, n = 3) {
  diverse_rules <- list()
  seen_rhs <- c()
  
  for (i in 1:length(rules)) {
    rule <- rules[i]
    rhs <- labels(rhs(rule))
    
    if (!(rhs %in% seen_rhs)) {
      diverse_rules <- c(diverse_rules, rule)
      seen_rhs <- c(seen_rhs, rhs)
    }
    
    if (length(diverse_rules) == n) break
  }
  
  return(diverse_rules)
}

# Funzione per interpretare una regola
interpret_rule <- function(rule) {
  lhs <- labels(lhs(rule))
  rhs <- labels(rhs(rule))
  
  cat("Se un individuo:", "\n")
  for(item in lhs) {
    cat("- ", item, "\n")
  }
  cat("Allora è probabile che anche:", "\n")
  cat("- ", rhs, "\n")
  cat("Con una confidenza di", round(quality(rule)$confidence, 2), 
      "e un lift di", round(quality(rule)$lift, 2), "\n\n")
}

calculate_digital_financial_literacy_score <- function(data) {
  # Knowledge component (qk7_4, qk7_5, qk7_6)
  knowledge_score <- with(data, 
    (qk7_4 == 0) + (qk7_5 == 1) + (qk7_6 == 0)
  )
  
  # Behaviour component (qs2_6, qs2_7, qs2_8, qs3_13)
  behaviour_score <- with(data,
    (qs2_6 %in% c(4, 5)) + 
    (qs2_7 %in% c(1, 2)) + 
    (qs2_8 %in% c(4, 5)) + 
    (qs3_13 %in% c(1, 2))
  )
  
  # Attitude component (qs4_1, qs4_2, qs4_3)
  attitude_score <- with(data,
    (qs4_1 %in% c(4, 5)) + 
    (qs4_2 %in% c(1, 2)) + 
    (qs4_3 %in% c(4, 5))
  )
  
  # Calculate raw score (0-10)
  raw_score <- knowledge_score + behaviour_score + attitude_score
  
  # Scale the score to 0-100
  scaled_score <- raw_score * 10
  
  return(scaled_score)
}
